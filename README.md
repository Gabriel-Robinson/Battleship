# Battleship (Console - Java)

A console-based implementation of the classic Battleship game written in Java.  
Players take turns attacking coordinates until one player’s fleet is fully sunk.

## Features
- 10x10 board
- Random ship placement for both players
- Turn-based gameplay
- Input validation for attack coordinates (A–J, 0–9)
- Prevents attacking the same coordinate twice
- Reports results: Hit, Miss, and Hit + Sunk
- Board display with labeled rows and columns
